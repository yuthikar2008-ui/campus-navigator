# Campus Navigator 🧭

An interactive web-based campus navigation prototype designed to help students find important campus destinations easily.

## 🌐 Live Demo
[Open Campus Navigator](https://lovely-kashata-f9ece1.netlify.app/)

## ✨ Features
- Search for campus destinations
- Explore popular places such as the library, academic block, and cafeteria
- Classroom finder interface
- Nearby campus facilities
- Save favourite destinations
- Route preview interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.

## 📌 Project Note
This is an interactive prototype. Campus locations and route information are illustrative and are not connected to live GPS navigation.
